# Unit Converter

## Problem Statement

Unit conversion is something we use quite often in studies and in daily
life. Sometimes we need to convert kilometres into metres, kilograms into
grams, Celsius into Fahrenheit, or one unit of data into another.

Doing these calculations manually every time can be a little confusing
and there is also a chance of making a mistake. So, I decided to make a
simple Python program that can do these conversions in one place.

## Objective

The main purpose of this project is to make unit conversion quick and
easy.

The project is also made to help me understand how Python can be used to
create a small practical application using functions, conditions,
input/output and different Python files.

## Target Users

This project can mainly be used by:

- Students
- Python beginners
- Anyone who needs a quick unit conversion

## Scope of the Project

The project currently includes six types of converters:

- Weight Converter
- Temperature Converter
- Length Converter
- Time Converter
- Data Converter
- Speed Converter

The program works through a simple menu. The user selects the required
converter, enters a value and gets the converted result.

The project also keeps a history of the conversions that have been done.

## Main Features

- Easy menu-based interface
- Weight conversion
- Temperature conversion
- Length conversion
- Time conversion
- Data conversion
- Speed conversion
- Conversion history
- Basic input error handling
- Separate Python files for different converters

## Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

## Expected Outcome

After completing this project, the user should be able to perform
different common unit conversions without doing the calculations
manually.

The project also helped me understand how a Python project can be divided
into different files and functions instead of writing everything in one
large file.
